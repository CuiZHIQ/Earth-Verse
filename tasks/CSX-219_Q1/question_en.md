# Oso Rainfall-Relief-Runout Threshold Ledger

A technical reviewer is building a deterministic ledger for the March 22, 2014 Oso landslide from the local event package. Compute the five threshold groups below and return the label generated by the rule. This is a calculation task; use only the local numeric and report fields named in the definitions.

Use these definitions:

- `event_day_mean_mm`: mean of the available event-day precipitation summaries.
- `antecedent_mean_mm`: mean of the two 14-day precipitation totals for March 8-21, 2014.
- `rainfall_load_mm = antecedent_mean_mm + event_day_mean_mm`.
- `antecedent_share = antecedent_mean_mm / rainfall_load_mm`.
- `relief_proxy_m_per_km`: absolute elevation difference between the local lowland daily-weather point and the local gridded mountain point, divided by their haversine distance in kilometers.
- `slope_proxy_degrees`: `atan(elevation_difference_m / horizontal_distance_m)` converted to degrees.
- `runout_area_ratio_mi_per_sq_mi`: reported road/runout length in miles divided by reported overrun area in square miles; use `1.0 mile` for "nearly a mile."
- `image_pair_score`: count of analytic pre/post image-change products with both `pre_count > 0` and `post_count > 0`.
- `exposure_normalized_index_per_100k`: `(reported fatalities + reported covered homes_or_structures) / context_population * 100000`.

Apply these thresholds:

- Rainfall/wetness passes when `rainfall_load_mm >= 150`, `event_day_mean_mm <= 2`, and `antecedent_share >= 0.95`.
- Relief passes when `relief_proxy_m_per_km >= 100`.
- Runout/area passes when `runout_area_ratio_mi_per_sq_mi >= 1.5` and reported average speed is at least `30 mph`.
- Image-pair count passes when `image_pair_score >= 1`.
- Exposure-normalized impact passes when `exposure_normalized_index_per_100k >= 5`.
- The final label is `passes_rain_relief_runout_4of5_thresholds` when rainfall/wetness, relief, and runout/area all pass and at least four of the five threshold groups pass.
